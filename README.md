# Ciudad Viva

**Ciudad Viva** es una plataforma diseñada para funcionar como la agenda cultural y social de referencia para la ciudadanía. Su objetivo es conectar a las personas con la oferta de ocio, cultura y actividades de su entorno inmediato de forma intuitiva, accesible y actualizada.

Al acceder al servicio, el usuario selecciona la ciudad de interés y el sistema despliega automáticamente toda la programación prevista para los próximos 30 días naturales a partir de la fecha en curso.

Para facilitar una búsqueda personalizada y ágil, la plataforma incorpora un sistema de filtros avanzados que permite acotar los resultados según:

- **Categoría temática:** música, teatro, deporte, infantil, conferencias, ferias, etc.
- **Municipio / Barrio:** acotación geográfica específica.
- **Lugar:** recintos concretos (teatros, plazas, centros cívicos, polideportivos).
- **Precio:** eventos gratuitos, de pago o por rangos de coste.

Los resultados se presentan mediante un catálogo visual en formato de tarjetas (*cards*), diseñadas para ofrecer un vistazo rápido a la información esencial: título, fecha, hora, ubicación principal y precio/etiqueta de gratuidad. Cada tarjeta cuenta con un botón de acción **«Ver detalle»**, que dirige al usuario a una ficha completa con la descripción extendida del evento, cartel publicitario, mapa de acceso, organizadores y enlaces para la reserva o compra de entradas.
